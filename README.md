# E-Fy-A Techtainment Book

## Local setup

1. Import `proj1.sql` into MySQL using phpMyAdmin or the MySQL command line.
2. Set database connection values using the `DB_HOST`, `DB_USER`, `DB_PASSWORD`, and `DB_NAME` environment variables, or create `php/config.local.php` based on `php/config.local.example.php`.
3. Run the project through Apache, for example with XAMPP.

`php/config.local.php` is intentionally ignored by Git. Keep local database credentials out of tracked files.
